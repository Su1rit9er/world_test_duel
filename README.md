# World Test Duel

Учебный бот для MAX. Можно проходить тренировки, играть с другом по коду, искать случайного соперника или соревноваться с ботом. Есть работа над ошибками, статистика, история игр, рейтинг и достижения.

В базе 355 вопросов:
- математика и русский язык 5-11 классы
- информатика 7-11 классы.

Для старших классов добавлены короткие задания по темам ЕГЭ. Предмет и класс выбираются в профиле.

## Как играть

Управление через кнопки. Чтобы открыть главное меню, напишите "меню".

В каждой игре пять вопросов. За правильный ответ даётся один балл. В дуэлях на вопрос отводится 30 секунд, а если не ответить, он будет пропущен без балла. Открытие меню не останавливает таймер. В тренировках ограничения по времени нет.

Для игры с другом отправьте ему код или ссылку из приглашения. У обоих должны совпадать предмет и класс. Рейтинг учитывает дуэли с другими игроками.

Ошибки из тренировок и дуэлей сохраняются в разделе "Мои ошибки". Правильный ответ при повторении убирает вопрос из этого списка.

## Запуск

В проекте используется Python 3.14.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Создайте `.env` рядом с `main.py` и укажите токен:

```env
MAX_BOT_TOKEN=ваш_токен
```

Проверьте подключение и запусти бота:

```bash
python main.py --check
python main.py
```

Для проверки без MAX:

```bash
python main.py --console
```

Выход из консольного режима `/exit`.

На один токен должна работать одна копия бота. Файл `max-ca.pem` нужен для проверки сертификата MAX.

## Docker

После настройки `.env`:

```bash
docker compose up -d --build
```

Просмотр логов и остановка:

```bash
docker compose logs -f --tail=50
docker compose down
```

## Структура проекта

- `main.py` - запуск и настройки подключения.
- `app.py`, `router.py`, `models.py` - обработка действий, регистрация команд и формат ответов.
- `quiz.py`, `duel.py` - тренировки и дуэли.
- `prefs.py`, `progress.py` - настройки профиля и сводки результатов.
- `store.py`, `storage.py` - SQL, транзакции и работа с SQLite.
- `screens.py`, `view.py`, `max_adapter.py` - кнопки, оформление и события MAX.
- `backend.py`, `sender.py`, `transport.py` - обработка событий, таймеры, очереди отправки и HTTP.

Вопросы находятся в `questions.json`. Старые задания в `questions_legacy.json` используются для повторения ранее сохранённых ошибок. Источники описаны в [QUESTION_SOURCES.md](QUESTION_SOURCES.md).

Новые действия регистрируются через `app.add`. Это позволяет добавлять команды и кнопки без изменения MAX-адаптера.

## Данные и тесты

Статистика, настройки и ошибки хранятся в SQLite: локально в `stats.db`. В Docker в `/data/stats.db` в постоянном томе. Незавершённые игры и очередь сообщений находятся в памяти и сбрасываются после перезапуска.

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

Проверяются игровые сценарии, кнопки, таймеры, сохранение результатов и база вопросов. Тесты используют временные базы и подмену HTTP, поэтому игровые сообщения в MAX не отправляются.
